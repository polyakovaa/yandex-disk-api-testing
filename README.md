# Yandex Disk API

Автотест UI (Selenium / [py-selenium-auto](https://github.com/Polmik/py-selenium-auto)) и REST API ([Яндекс.Диск](https://yandex.ru/dev/disk-api/doc/ru/))


## Структура

```
disk_api/
    api/            HTTP-клиент и методы Disk API
    models/         Config, тестовые данные, модели ответов
    pages/          Page Object (главная, логин, диск, viewer, изображение)
    providers/      .env, test_data.json, startup браузера
    resources/      settings.json, test_data.json, тестовое изображение
    browsers/       настройки для поддержки chrome и firefox
    steps/          шаги логина
    tests/          conftest, сценарий
    utils/          файлы, рандом, логи, разбор src изображения
```

## Сценарий

1. [UI] Перейти на сайт https://disk.yandex.ru/
2. [UI] Авторизоваться.
3. [API] С помощью запроса к API добавить текстовый файл со случайным текстом, убедиться что ответ вернулся с кодом 201.
4. [UI] Не обновляя страницу убедиться, что добавленный файл появился на диске, имя файла соответствует отправленному.
5. [UI] Открыть документ в новой вкладке, убедиться что содержимое документа соответствует содержимому в отправленном файле, закрыть вкладку.
6. [API] Изменить расширение файла на диске на jpg, используя API запрос, убедиться, что получен ответ с кодом 201.
7. [UI] Не обновляя страницу убедиться, что расширение файла изменилось.
8. [API] Загрузить изображение с тем же именем файла, что и измененный в предыдущем шаге с заменой, получен код ответа 201.
9. [UI] Открыть изображение, убедиться, что изображение соответствует загруженному в предыдущем шаге. Закрыть изображение.
10. [UI] Перетащить файл с изображением в корзину.
11. [API] С помощью API запроса убедиться, что файл из предыдущего шага находится в корзине.

13.[UI] Не обновляя страницу убедиться, что изображение вновь присутствует на диске.
14. [API] Используя запрос к API безвозвратно удалить изображение из Диска, убедиться, что получен ответ с кодом 204.
15. [UI] Не обновляя страницу убедиться, что изображение отсутствует на диске.


## Запуск

Требования: Python >= 3.10

```
cd disk_api
python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
```

Скопируйте .env.example в .env и заполните:

```
YANDEX_BASE_URL=https://cloud-api.yandex.net/v1/disk/
YANDEX_TIMEOUT=30
YANDEX_OAUTH_TOKEN=<OAuth-токен приложения>
YANDEX_EMAIL=<логин тестового пользователя>
YANDEX_PASSWORD=<пароль>
```

Тест:
```
pytest tests/test_disk_api.py -v
```

Логи: logs/disk_api.log.

Браузер задается в resources/settings.json (browserName: chrome или firefox)
